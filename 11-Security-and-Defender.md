# Security and Microsoft Defender

## Security layers

- Entra ID, Conditional Access, MFA and PIM
- Azure Policy and RBAC
- Prisma Access and Cloud NGFW
- NSGs and private endpoints
- WAF for public web applications
- Defender for Cloud capabilities
- code and secret scanning in GitHub Enterprise
- central logging and incident response.

## Defender model

Free/baseline Defender capabilities and reporting are generally enabled centrally. Paid workload plans, such as Defender for Containers or Defender for AKS, may require a service-level risk and funding decision.

There is not yet a universal platform mandate in the meeting summary requiring every paid Defender plan for every applicable resource type. Coverage may therefore vary by service.

## Required service record

Each service should state:

- applicable Defender plans
- enabled/disabled status
- funding owner
- security risk decision
- alert destination
- incident owner
- review date.
