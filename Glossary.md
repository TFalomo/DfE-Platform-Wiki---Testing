# Glossary

| Term | Meaning |
|---|---|
| AD DS | Active Directory Domain Services |
| ADR | Architecture Decision Record |
| AKS | Azure Kubernetes Service |
| B2B | Entra ID business-to-business guest collaboration |
| CDS | Inherited citizen/digital-service Azure estate |
| CIP/SIP | Separate platform tenant created as a flexible alternative to Tier 1; confirm preferred current name |
| Cloud NGFW | Palo Alto Networks Cloud Next-Generation Firewall for Azure |
| ELZ | Enterprise Landing Zone |
| Entra ID | Microsoft cloud identity and access service, formerly Azure AD |
| ExpressRoute | Private connectivity between on-premises networks and Microsoft cloud services |
| FCS | Inherited funding-service Azure estate |
| GlobalProtect | Palo Alto remote-access client/service |
| IaC | Infrastructure as Code |
| PIM | Microsoft Entra Privileged Identity Management |
| Prisma Access | Palo Alto Networks SaaS-hosted security and access service |
| Private Endpoint | Private IP interface providing access to an Azure PaaS service |
| RPO | Recovery Point Objective |
| RTO | Recovery Time Objective |
| Tier 0 | Identity/security services whose compromise can compromise the wider estate |
| Tier 1 | Original centrally operated DfE Azure environment |
| UDR | User-defined route |
| vWAN | Azure Virtual WAN |
| WAF | Web Application Firewall |
